# express-myapp

Basic Express app scaffolded with Express Generator (Pug templates).

## Requirements

- Node.js (LTS recommended)
- npm

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

Open: http://localhost:3000

## Project structure

- `app.js` – Express app setup
- `bin/www` – HTTP server entrypoint
- `routes/` – Route handlers
- `views/` – Pug templates
- `public/` – Static assets
